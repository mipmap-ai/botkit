# Bot references

Your profile's `References:` field lists file names, one per dash line:

```
References:
- style-guide.md
```

`ROOT` is the bot computer's private workspace folder.

1. Read `ROOT/references/INDEX.md` once and find the line for each listed file. It says what the file is and when to read it.
2. Open `ROOT/references/<file>` only when the task matches that description. Don't preload every file.
3. References are read-only. Don't edit them unless the owner says to.
4. If a listed file or its index line is missing, tell the owner once; don't guess its contents.

Ignore index entries for files your profile doesn't list.
